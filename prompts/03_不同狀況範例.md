# 03｜四種狀況的填好版本

課堂上最常見的四種狀況。找到你的那一種，照著填。

| | 狀況 | 往哪一段 |
|---|---|---|
| A | 出生時間完整，八題也寫完了 | [狀況 A](#狀況-a出生時間完整八題也寫完了) |
| B | 不知道出生時間 | [狀況 B](#狀況-b不知道出生時間只能填中午-1200) |
| C | 自傳只來得及寫四題 | [狀況 C](#狀況-c自傳只來得及寫四題) |
| D | 不想把自傳貼進 AI | [狀況 D](#狀況-d不想把自傳貼進-ai) |

> **重要：下面所有範例的星盤欄位都是佔位符，不是真人的盤。**
> `〔你的星座〕` `第〔N〕宮` 這些一定要換成你在占星之門查到的實際結果。
> 星盤是每個人不一樣的那一半，範例給不了你——範例能給的是「自傳要寫到什麼程度」。
>
> 自傳與目標的內容是虛構的練習範例，只是示範顆粒度，不要照抄。

## 狀況 A｜出生時間完整，八題也寫完了

這是最完整的版本。下面這份自傳，就是 [02 填寫說明與範例](02_填寫說明與範例.md) 那張「太籠統 vs 夠具體」表格右欄八題接起來的樣子，同一個人。

```
【我的星盤】
太陽：〔你的星座〕座 第〔N〕宮
月亮：〔你的星座〕座 第〔N〕宮
上升：〔你的星座〕座
水星：〔你的星座〕座 第〔N〕宮
金星：〔你的星座〕座 第〔N〕宮
火星：〔你的星座〕座 第〔N〕宮
木星：〔你的星座〕座 第〔N〕宮
土星：〔你的星座〕座 第〔N〕宮

【我的自傳】
1. 我今年 42 歲，現在的身分是區公所行政人員，下班時間自己做手工皂拿去市集賣。
2. 我做過最久的一件事是同一個行政職，做了 14 年，中間換過兩個科室。
3. 我人生最大的一次轉折是 31 歲那年家裡出事，我把準備兩年的留學計畫退掉，回家扛。
4. 別人常說我可以把很亂的東西講得讓人聽懂，同事有事都先來問我。
5. 我自己知道但不太承認的缺點是：只要沒把握做到滿分，我就會一直拖著不開始，然後怪時間不夠。
6. 我最近三年最挫折的事是去年市集連續三場都沒賣掉一半，收攤時我在車上坐了半小時。
7. 我把一團亂的流程重畫成一張圖的時候會忘記時間，可以做到半夜三點。
8. 如果錢不是問題，我想開一間只收六個人的教室，每週講一堂，讓人做完可以帶回家。

【我的目標】
短期：三個月內把手工皂上架到一個網路平台
中期：兩年內每月靠副業多三萬
長期：五年後不靠正職收入也能活，一週只上三天班
```

接著照 [01](01_資料區塊與三輪提示詞.md) 的順序貼輪次 1、2、3。

**這個版本會拿到什麼**：三輪都完整，輪次 3 的「哪裡在逆著自己」會最有料——因為它有目標可以比對。
以這份為例，第 5 題的拖延跟第 6 題的市集挫折會被串起來，短期目標「三個月內上架」很可能就是它指出你會卡住的那一步。

## 狀況 B｜不知道出生時間，只能填中午 12:00

**先講清楚**：不知道時間不是你的問題，很多人都這樣。
今天先用中午跑，你星盤的一半照樣是準的。等你問到時間，回來重跑一次，那時候會更有感。

**哪一半準、哪一半不準**

| 大致可用 | 不準（標「待確認」，值照樣留著） |
|---|---|
| 太陽、水星、金星、火星、木星、土星在哪個星座 | 上升星座 |
| 月亮星座（移動較快，時間差太多時也可能換座） | 全部十二宮的宮位 |

原因：上升每約兩小時換一個星座，宮位整組會跟著轉。

> **做法是「標記」，不是「留白」。**
> 課程正本的 Plan B 就是先填中午 12:00 把盤跑出來，把上升與十二宮標成待確認——留白的話，AI 連你有沒有查過都不知道，反而更容易自己腦補。

**資料區塊這樣填**

```
【我的星盤】
（我不知道自己幾點出生，這張盤是用中午 12:00 推算的。
　下面每一行的「第幾宮」和「上升」都是這樣推出來的，
　請當成待確認資訊，不要拿來當結論的依據；星座的部分照常使用。）

太陽：〔你的星座〕座 第〔N〕宮（宮位待確認，不要拿來當結論依據）
月亮：〔你的星座〕座 第〔N〕宮（宮位待確認，不要拿來當結論依據）
上升：〔你的星座〕座（待確認，不要拿來當結論依據）
水星：〔你的星座〕座 第〔N〕宮（宮位待確認，不要拿來當結論依據）
金星：〔你的星座〕座 第〔N〕宮（宮位待確認，不要拿來當結論依據）
火星：〔你的星座〕座 第〔N〕宮（宮位待確認，不要拿來當結論依據）
木星：〔你的星座〕座 第〔N〕宮（宮位待確認，不要拿來當結論依據）
土星：〔你的星座〕座 第〔N〕宮（宮位待確認，不要拿來當結論依據）

【我的自傳】
1. 我今年 29 歲，現在的身分是連鎖餐飲的店長，帶八個工讀生。
2. 我做過最久的一件事是餐飲現場，做了 7 年，從外場做到店長。
3. 我人生最大的一次轉折是 25 歲被拔擢當店長，三個月內走掉四個老員工。
4. 別人常說我臨場反應快，出事的時候我最冷靜。
5. 我自己知道但不太承認的缺點是我很難相信別人做得好，最後全部自己扛。
6. 我最近三年最挫折的事是去年身體撐不住請了兩週長假，回來發現店照樣在轉。
7. 我排班表跟動線的時候會忘記時間。
8. 如果錢不是問題，我想開一間自己的店，只做十個位子。

【我的目標】
短期：三個月內把交接流程寫成一份誰都看得懂的手冊
中期：三年內開一間自己的小店
長期：五年後不用每天站在現場也能營運
```

> 開頭那三行括號的說明**不是講義模板的原文**，是給不確定出生時間的人加的註記。
> 加了它，AI 就不會把宮位當成確定事實往下推。
>
> 第 6 題示範的是隱私尺度：**身體的事寫到「撐不住、請了兩週長假」就夠 AI 分析了**，不用寫病名、住院細節或用藥。詳見 [07 兩條紅線](../07_兩條紅線.md)。

**跑完之後**：如果 AI 還是把宮位講得像確定的事，貼這句退回去——

```
我的宮位與上升是用中午 12:00 推算的，屬於待確認資訊。請把依賴宮位與上升的結論標示出來，並用星座的部分重講一次結論。
```

**問到出生時間之後**：回占星之門重新產一次盤，把上升與宮位補進資料區塊，三輪重跑一次。你會讀到不一樣的東西。

## 狀況 C｜自傳只來得及寫四題

十分鐘寫不完是正常的。**寫幾題算幾題**，模板帶回家，晚上補完再跑一次。

**如果只寫得完四題，可以優先寫這四題**：3、5、6、7

| 題 | 為什麼優先 |
|---|---|
| 3 我人生最大的一次轉折 | 有時間點、有事件，最好對應星盤 |
| 5 我不太承認的缺點 | 這題決定報告會不會刺到你 |
| 6 最近三年最挫折的事 | 提供近期證據，不是十年前的自己 |
| 7 做什麼會忘記時間 | 天賦那一輪最重要的原料 |

> 這個優先順序是依講義邏輯排的**建議**，不是講義原文，也不是講師的規定。
> 課程正本的說法只有一句：**有幾題寫幾題。** 你覺得別題更有代表性，就先寫別題。

**資料區塊這樣填（沒寫的題目整題刪掉，不要留空白編號）**

```
【我的星盤】
太陽：〔你的星座〕座 第〔N〕宮
月亮：〔你的星座〕座 第〔N〕宮
上升：〔你的星座〕座
水星：〔你的星座〕座 第〔N〕宮
火星：〔你的星座〕座 第〔N〕宮
土星：〔你的星座〕座 第〔N〕宮
（金星、木星我在盤上還沒找到，先不填）

【我的自傳】
3. 我人生最大的一次轉折是 48 歲收掉開了十二年的店，改成只接熟客訂單。
5. 我自己知道但不太承認的缺點是我怕麻煩別人，寧可自己慢慢弄到半夜。
6. 我最近三年最挫折的事是老客人一個一個退休，新客人我不知道去哪裡找。
7. 我配貨、擺貨的時候會忘記時間。
（其餘四題今天沒寫完，先不提供）

【我的目標】
短期：三個月內把熟客名單整理成一份可以聯絡的清單
中期：兩年內固定訂單能養活自己
長期：五年後把這門手藝交給一個人
```

> 括號那兩行說明也不是模板原文，是為了讓 AI 知道「這是還沒寫，不是沒有」。
> 少了這一句，AI 容易自己腦補你沒寫的部分。

**跑完之後怎麼補**：不要重開對話。在同一個對話裡直接追問——

```
我補一件自傳沒寫到的事：〔補的內容〕。
請只修正受這件事影響的結論，其他不用重寫。
```

**這個版本會拿到什麼**：輪次 1、2 照樣有東西，因為第 3、5、6、7 題就是佐證的主力。
輪次 3 會比較弱——目標那三行如果也很空，第三輪幾乎沒東西可比。所以目標三行再趕都要寫。

## 狀況 D｜不想把自傳貼進 AI

**這一關沒有人會逼你。** 不想貼就不用貼，看講師示範、回家再決定要不要用，完全可以。
下面這個降階版是給「想試試看，但不想把整段人生交出去」的人。

### 降階版怎麼跑

只貼兩塊：**星盤 ＋ 2–3 句去識別化的事件**。

去識別化的意思是：**只留「時間點 ＋ 發生什麼 ＋ 結果」，把人名、公司名、地點、職稱細節全部拿掉。**

| 原本會寫的 | 降階版寫成 |
|---|---|
| 我在大明食品當採購，被林經理當眾罵到辭職 | 三年前在一個職場衝突後離職 |
| 我先生王小明外派新加坡兩年，我一個人帶兩個孩子 | 有兩年是我一個人撐家裡 |
| 2019 年開刀住院三個月，公司沒等我 | 2019 年那段身體出狀況的時期，工作也中斷了 |

**資料區塊這樣填**

```
【我的星盤】
太陽：〔你的星座〕座 第〔N〕宮
月亮：〔你的星座〕座 第〔N〕宮
上升：〔你的星座〕座
水星：〔你的星座〕座 第〔N〕宮
金星：〔你的星座〕座 第〔N〕宮
火星：〔你的星座〕座 第〔N〕宮
木星：〔你的星座〕座 第〔N〕宮
土星：〔你的星座〕座 第〔N〕宮

【我的自傳】
（我只提供去識別化的三件事，不提供完整自傳。）
1. 三十歲前後有一次職涯中斷，之後換了一個完全不同的行業。
2. 這幾年做得最久的一件事，是一個需要長期照顧別人的角色。
3. 我最投入的時候，是在把很亂的事情整理成一套流程的時候。

【我的目標】
短期：三個月內把手上的工作交出去一件
中期：兩年內換到一個不用長期待命的位置
長期：五年後靠自己的專業接案為主
```

### 代價要先知道

這不是「一樣好但更安全」，是**用一部分品質換隱私**，你自己決定值不值得：

- **輪次 1 會變弱。** 它的核心要求是「把自傳裡的真實經歷跟星盤配置對應起來」。事件只剩三句，能對上的就少。AI 照規則會回你「這點僅為星盤通則，你的自傳沒有對應證據」——**那不是它壞掉，是它照規則辦事**，也正好證明規則有在運作。
- **輪次 3 幾乎跑不動。** 它要比對的是「你的目標 vs 你的天賦 vs 你的實際經歷」。經歷太薄，第 1、2 題就沒東西可比，只剩第 3 題的建議還有點用。
- **輪次 2 影響最小。** 天賦那一輪吃的主要是「你做什麼會忘記時間」這類線索，一句話就夠。

### 三個折衷選項

1. **只砍自傳，留目標。** 目標三行是你自己的規劃，通常不涉及別人的隱私。留著它，輪次 3 至少跑得動一半。
2. **課堂只看，回家再跑。** 帶走 [01](01_資料區塊與三輪提示詞.md) 的模板，在你信任的環境、用你自己的帳號跑。
3. **先關掉訓練用途再貼。** 進你那個 AI 的帳號設定，把「用我的對話改進模型」關掉，或改用暫時對話／無痕對話再貼〔待驗證：各工具的設定位置與名稱都不一樣，自己看過一次才算數〕。

> 判斷方法只有一句：**「如果這段話明天原封不動出現在班級群組裡，我會不會後悔？」** 會後悔的，換掉或刪掉。

## 四種狀況共通的一件事

貼之前看一眼：自傳裡有沒有別人的全名、公司全名、完整生辰，或你不想留在網路上的細節。
有就換成關係描述——「我先生」「一位合作七年的夥伴」「前一個主管」。

**分析品質不會因此變差，因為 AI 要的是事件，不是名字。**

完整的去識別化對照表與越界警訊，見 [07 兩條紅線](../07_兩條紅線.md)。
