# 02｜填寫說明與範例

同一組提示詞，兩個人跑出來的品質可以差很多。差別不在 AI，在你餵它什麼。
這一張講的就是：哪裡填錯，會壞在哪。

提示詞原文在 [01 資料區塊與三輪提示詞](01_資料區塊與三輪提示詞.md)｜填好的完整範例在 [03 不同狀況範例](03_不同狀況範例.md)

---

## 每一段在做什麼

| 段落 | 作用 |
|---|---|
| 【我的星盤】 | 這是**容器**。它是一組不是你自己挑的外部結構，AI 不能一路順著你講，因為盤是固定的 |
| 【我的自傳】 | 這是**燃料**。沒有它，AI 只講得出星座通則，跟網路星座文一樣 |
| 【我的目標】 | 輪次 3 的比對基準。沒有它，「哪裡在逆著自己」這一題無從比起 |
| 「不要說好聽話，準確比舒服重要」 | 擋掉討好模式。AI 的預設行為是讓你滿意 |
| 「每個結論都要標明依據」 | 讓你驗收得了。標不出依據的結論，就是它掰的 |
| 「找不到佐證的，就直接說沒有證據」 | 整堂課最有價值的一句。給它一條「承認不知道」的退路，它才不用編 |
| 「承上」 | 輪次 2、3 靠這兩個字接住前面。所以三輪必須在同一個對話 |

> 規則那幾行是煞車，不是客套話。刪掉它，報告會立刻回到好聽話模式。

## 寫法要點（九組對照）

| 位置 | 寫法 | 會怎樣 |
|---|---|---|
| 星盤有一行看不懂 | ✕ 隨便猜一個星座填上去 | AI 會把你猜的當事實，整份報告從錯的地基長出來，而且你看不出來 |
| | ✓ 那一行整行刪掉，有幾顆貼幾顆 | AI 只用你真的查到的資料，結論少但可信 |
| 不知道出生時間 | ✕ 用中午 12:00 跑出來的上升與宮位，當成確定的事往下推 | 上升每約兩小時換一個星座、宮位整組會跟著轉，等於拿沒查證的東西當地基 |
| | ✓ 值照樣貼，但每一行標「待確認，不要拿來當結論依據」 | 它會把結論的重量壓在太陽、月亮與各行星的星座上——那一半大致照樣可用 |
| 自傳的長度 | ✕ 每題五個字打發（「工作」「還好」） | 沒有可對應的事件，AI 只能回星座通則，跟網路文章沒兩樣 |
| | ✓ 每題至少一個具體事件，有時間、有結果 | 星盤才有東西可以對得上，才長得出「你這個模式從那件事就開始了」 |
| 自傳的誠實度 | ✕ 只寫優點，缺點寫「太認真」「對自己要求太高」 | 你給它的是履歷，它回你的就是稱讚 |
| | ✓ 第 5、6 題老實寫 | 這兩題是整份報告會不會刺到你的關鍵 |
| 三階段目標 | ✕ 「變有錢」「過得更好」 | 輪次 3 的「哪裡在逆著自己」沒有東西可以比對 |
| | ✓ 「每月多三萬被動收入」「年底前開第一堂課」 | AI 才能對照你的天賦，指出你會卡在哪一步 |
| 對話管理 | ✕ 三輪各開一個新對話 | 「承上」變成空的，AI 從頭重猜，第二、三輪品質整個掉下來 |
| | ✓ 三輪都在同一個對話 | 它記得前面的結論，第三輪才接得住第一輪 |
| 追問方式 | ✕ 「請再深入一點」 | 它會用更多形容詞把同一件事重講一次 |
| | ✓ 「第 2 點的依據是星盤哪裡、自傳哪一句？」 | 沒依據的它會鬆口，你就知道哪幾段該刪 |
| 提示詞本身 | ✕ 自己把規則那幾行刪掉，覺得太囉嗦 | 煞車被拆了，回到人人適用的好聽話 |
| | ✓ 整段照貼，只改資料區塊 | 這幾句就是為了擋唬爛而存在的 |
| 隱私尺度 | ✕ 寫進第三人全名、公司全名、完整生辰、財務或健康細節 | 這些不是分析必需，卻永久離開你手上 |
| | ✓ 換成關係與事件（「一位合作七年的夥伴」「那段身體出狀況的時期」） | 分析品質不變，風險降到最低 |

> **健康狀況這一條要講清楚。**
> **你自己的**健康狀況要不要寫，你決定——但寫下去就**永久留在對方系統裡**，事後刪對話也不保證刪得掉，所以只寫到「那段身體出狀況的時期對我的影響」這個程度就夠了，不必寫病名、用藥或就診紀錄。
> **別人的**健康狀況**一律不要寫**。家人的病情、朋友的診斷，那不是你的東西，你沒有立場替他決定要不要交出去。
> 完整的去識別化對照表在 [07 兩條紅線](../07_兩條紅線.md)。

## 自傳八題：太籠統 vs 夠具體

原則一句話：**寫得出「什麼時候、發生什麼、結果如何」的，就夠具體。**

| # | 題目 | ✕ 太籠統 | ✓ 夠具體 |
|---|---|---|---|
| 1 | 我今年 ___ 歲，現在的身分是 ___ | 「上班族」 | 「42 歲，在區公所做行政，下班時間自己做手工皂拿去市集賣」 |
| 2 | 我做過最久的一件事，做了 ___ 年 | 「工作」 | 「同一個行政職做了 14 年，中間換過兩個科室」 |
| 3 | 我人生最大的一次轉折 | 「換過工作」 | 「31 歲那年家裡出事，我把準備兩年的留學計畫退掉，回家扛」 |
| 4 | 別人常說我 | 「人很好」 | 「同事有事都先來問我，說我可以把很亂的東西講得讓人聽懂」 |
| 5 | 我知道但不太承認的缺點 | 「有點懶」 | 「只要沒把握做到滿分，我就會一直拖著不開始，然後怪時間不夠」 |
| 6 | 我最近三年最挫折的事 | 「工作不順」 | 「去年市集連續三場都沒賣掉一半，收攤時我在車上坐了半小時」 |
| 7 | 我做什麼會忘記時間 | 「看影片」 | 「把一團亂的流程重畫成一張圖，可以做到半夜三點」 |
| 8 | 如果錢不是問題，我想做 | 「環遊世界」 | 「開一間只收六個人的教室，每週講一堂，讓人做完可以帶回家」 |

> 上表右欄八題是**同一個人**，把它們接起來就是 [03 不同狀況範例](03_不同狀況範例.md) 狀況 A 的那份自傳。
> 想看完整長相，翻過去對照著看。

**兩個常見的坑**

- 第 5、6 題最多人寫得客套。這兩題如果都寫「太認真」「有點忙」，你會拿到一份很禮貌、也很沒用的報告。**真實比漂亮重要，AI 讀得出你在客套。**
- 「夠具體」不等於「寫很長」。上表右欄每題都在四十個字以內——**有時間點、有事件、有結果就夠了**，不需要寫成故事。

## 三階段目標怎麼寫

| 段 | ✕ | ✓ |
|---|---|---|
| 短期（3 個月內） | 「多存一點錢」 | 「三個月內把手工皂上架到一個網路平台」 |
| 中期（1–3 年） | 「事業有起色」 | 「兩年內每月靠副業多三萬」 |
| 長期（5 年以上） | 「過得更好」 | 「五年後不靠正職收入也能活，一週只上三天班」 |

再趕也要各寫一行。這三行空著，輪次 3 等於只跑了一半。

## 貼進去之前，最後三秒的檢查

1. 星盤那幾行，有沒有哪一行是我猜的？有就刪掉。
2. 自傳裡有沒有出現別人的全名、公司全名、完整生辰，或我不想留在網路上的細節？有就換成關係描述。
3. 我這份自傳如果被我媽看到，我會不會後悔？會的話——那部分寫到你願意的程度就好，**寫少不扣分，寫假才扣分。**
